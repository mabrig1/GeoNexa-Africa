# GeoNexa Africa

Nigeria-first geoscience intelligence platform. Initial scope: geological data catalogue, location-based EarthScan reports, field observations, human-supervised AI workflows, support and policy centre.

## Principles
- No claim of underground detection from imagery alone.
- All scientific claims require dataset provenance and uncertainty disclosures.
- Professional review before consequential geological recommendations.
- Tenant isolation, least privilege, auditable agent tools.

## Planned stack
Next.js / TypeScript frontend; FastAPI scientific services; PostgreSQL/PostGIS; object storage; controlled agent orchestration.

## Development status
Architecture initialized. No scientific models, live geological data or AI analysis are operational yet.

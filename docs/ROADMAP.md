# Implementation roadmap

1. Foundation: responsive dashboard, identity, organisation-scoped access, support tickets.
2. Evidence catalogue: PostGIS, dataset licence/provenance metadata, location search.
3. EarthScan: bounded data retrieval, deterministic geospatial analysis, citations and uncertainty.
4. GeoMind: supervised agent orchestration, tool allowlists, budgets and audit logs.
5. GeoWater: geophysical integrations and professional validation.

## Launch gates
No deployment with hard-coded secrets, cross-tenant access, unreviewed high-stakes conclusions, or unsupported claims of scientific accuracy.
